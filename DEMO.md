# Демонстрация базового агента

Это сценарий репетиции, не основного проекта. Две диалектические проверки пока
не реализованы и не демонстрируются как готовые.

1. Установить зависимости по README, задать ключ, модель и URL Groq в .env.
2. Из корня тренировочного репозитория:
   `.\.venv\Scripts\python -m rehearsal --provider groq --env-file .env`.
3. Показать пять исходных обращений, пять категорий и пять русских черновиков.
4. Открыть выведенный каталог runs: results.json и events.jsonl. Показать
   исходный ввод, инструкции, выход, токены и время; не открывать .env.
5. Проверить ошибочный вход:
   `.\.venv\Scripts\python -m rehearsal --messages missing-input-example.txt`.
   Ожидание: явная ошибка, ненулевой код выхода, никаких выдуманных результатов.

При недоступности модели сообщить ошибку и показать сохранённый прошлый прогон
с его временем, явно назвав его записью предыдущего запуска.
