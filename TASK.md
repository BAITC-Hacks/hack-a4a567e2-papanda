# Репетиция: пять обращений

Источник: задание пользователя в текущем разговоре, 2026-09-21.
Это тренировочный кейс, не основной конкурсный проект.

Обязательный результат: messages.txt с пятью исходными обращениями; скрипт,
который печатает категорию (справка / жалоба / другое) и один черновик ответа
на русском для каждого; короткий README с запуском и результатами.

Пользователь выбрал OpenAI Agents SDK для общего базового движка.
Поверх ОДНОГО базового результата нужны две независимые реализации проверки:
готовый DialecticAI и проверка с нуля без DialecticAI.
Сравниваются проверки, базовый агент не заменяется.

Методология пользователя: простейшее — само обращение. Развивается идея
обращения, не его содержание. Путь проверки: простейшее → развивающие факты →
противоположности → противоречие → разрешение (скачок). Противоречие может
находиться в самом обращении. При наличии противоречия строится план разрешения;
если разрешение не удалось, требуется уточнение у пользователя.
Не выдумывать противоречие ради заполнения структуры. Отсутствие данных и ошибка
API сами по себе не доказывают противоречие. Семантический эталон от пользователя
пока не получен: корректность философской трактовки остаётся непроверенной.

Разрешены параллельные агенты разработки. Нужен подробный журнал действий,
решений, проверок и ошибок без секретов. Основной репозиторий запрещено трогать.
